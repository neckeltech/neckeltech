## 🎓 Aprenda Java comigo

Os repositórios abaixo acompanham as aulas do canal. Cada um é um projeto **Spring Boot 3** pronto para clonar, rodar e estudar junto com o vídeo.

### 🔐 Segurança

| Projeto | O que você aprende |
|---|---|
| **[spring-security-basic-authentication](https://github.com/neckeltech/spring-security-basic-authentication)** ⭐ 14 · 🍴 8 | Autenticação e autorização com **Spring Security + Spring Boot 3**: filtro customizado de Basic Auth, `UserPrincipal`, perfis de acesso (roles) e usuários persistidos em MySQL com Spring Data JPA. |

### 🗄️ Trilha de persistência de dados — do JDBC ao Flyway

Uma sequência pensada para entender **o que acontece por baixo** antes de usar a abstração:

| # | Projeto | O que você aprende |
|---|---|---|
| 1 | **[aula-java-jdbc](https://github.com/neckeltech/aula-java-jdbc)** | JDBC puro: abrir conexão, executar SQL e mapear resultados manualmente, com tratamento de exceções próprio. |
| 2 | **[aula-java-jpa-hibernate](https://github.com/neckeltech/aula-java-jpa-hibernate)** | JPA + Hibernate com `persistence.xml` e `EntityManager` — o ORM sem a "mágica" do Spring Data. |
| 3 | **[aula-java-flyway](https://github.com/neckeltech/aula-java-flyway)** | Migrations versionadas com **Flyway** em um projeto Spring + MySQL, evoluindo o banco de forma segura e reproduzível. |

### 🌐 APIs REST

| Projeto | O que você aprende |
|---|---|
| **[rest](https://github.com/neckeltech/rest)** | `@RestController` em três níveis — **easy, medium e hard** — com DTOs, para sair do primeiro endpoint até uma API bem estruturada. |
